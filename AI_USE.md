# AI-use disclosure

- **Tool:** Claude Code wrote most of the initial code and docs. Codex assisted with later implementation, the Next.js migration, testnet setup, verification, and repository preparation. That includes the contracts, the Python backend, the dashboard, the checkout, the tests and the scripts.
- **Human role:** the team wrote the PRD (`docs/SenFund-PRD.docx`) and the build prompt (`docs/prompts/`). The team chose the scope, ran and reviewed the work, and authorized repository changes and publication. The team handled testnet funding and submission.
- **Planning artifacts:** `docs/BUILD_PLAN.md` was produced by the assistant from the PRD at the start of the session.
- **Not done by AI:** the team obtained testnet funds and signed the browser-wallet payment. AI assistants helped prepare and verify testnet transactions.
- **Generated content:** party names and bank data are fictional. Fiat conversion and the INR payout are simulated, and the UI labels them that way.
